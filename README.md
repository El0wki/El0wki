### 🚀 Projeto em Destaque: Sistema de Perícia Contábil
> **Status:** Freelance Full Stack (Equipe) · Jan 2025 - Presente
Desenvolvimento de uma plataforma para automação de cálculos judiciais e tributários, focada em substituir fluxos manuais por processos digitais seguros.

- **Stack:** Java (SpringBoot), Node.js, Next.js, TypeScript, MongoDB, Zustand, Zod, React-pdf, ExcelJS.
- **Destaque:** Integração entre motor de cálculo em Java e interface em Next.js, com foco em precisão de dados e automação de laudos profissionais.
